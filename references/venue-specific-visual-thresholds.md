# Venue-Specific Visual Thresholds

## Goal

Adjust main-deck and appendix thresholds by venue so the selected evidence matches community expectations.

## Main rules

- Use stricter main-deck thresholds for venues that reward benchmark rigor.
- Use lower qualitative thresholds for venues that reward visual evidence.
- Keep appendix thresholds below main-deck thresholds, but never so low that weak visuals flood the appendix.

## Typical tendencies

### ICLR
- Favor method and ablation evidence.
- Keep qualitative evidence secondary unless it is unusually strong.

### NeurIPS
- Favor result tables and ablation tables.
- Use a slightly stricter main-deck threshold.

### ACL / EMNLP / NAACL
- Reward qualitative examples and task comparison tables.
- Allow one extra qualitative slide when it adds a distinct type of evidence.

### CVPR / ICCV / ECCV
- Reward qualitative figures and multi-panel comparisons.
- Lower the qualitative insertion threshold when the examples are strong and non-redundant.
