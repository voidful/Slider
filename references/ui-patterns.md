# UI Patterns

## Purpose

Map rhetorical content to the right slide pattern.

## Pattern 1. Cover

Use for:
- title slide,
- final takeaway,
- strong teaser.

Structure:
- large centered title,
- short supporting line,
- minimal clutter.

## Pattern 2. Split

Use for:
- problem plus illustration,
- prior limitation plus comparison,
- method explanation plus diagram.

Structure:
- left text,
- right visual,
- clear visual focal point.

## Pattern 3. Bullets

Use for:
- concise conceptual points,
- limitations,
- future work,
- takeaways.

Rules:
- 3 to 5 bullets max,
- short phrases,
- strong spacing.

## Pattern 4. Metrics

Use for:
- main results,
- performance deltas,
- summary comparisons.

Rules:
- large typography,
- one dominant number,
- compact supporting labels.

## Pattern 5. Diagram

Use for:
- method overview,
- pipeline,
- training flow,
- architecture explanation.

Rules:
- simplify aggressively,
- show flow clearly,
- avoid dense replication of the original figure.

## Pattern 6. Table Focus

Use for:
- benchmark comparison,
- ablation summary.

Rules:
- show only necessary rows and columns,
- highlight the relevant comparison.

## Pattern 7. Caution

Use for:
- limitations,
- failure modes,
- caveats.

Rules:
- concise language,
- clear warning visual tone,
- no melodrama.

## Placeholder policy

When the figure cannot be extracted or redrawn confidently:
- use a clean placeholder block,
- state the intended role of the figure,
- do not fabricate imagery.
