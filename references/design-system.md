# Design System

## Design objective

Use restrained, modern, research-first design.

The style should feel:
- minimal,
- editorial,
- calm,
- premium,
- technically rigorous.

The style should not feel:
- like a startup landing page,
- overly decorative,
- gradient-heavy,
- noisy,
- generic.

## Typography

Use strong visual hierarchy.

Prefer:
- large slide titles,
- concise body text,
- limited annotation text,
- high contrast,
- consistent weight changes.

Use argumentative titles when possible.

Good:
- masked prediction forces broader contextual reasoning
- most of the gain comes from better representation learning

Bad:
- method
- results
- experiments

## Color

Use a restrained palette.

Default strategy:
- neutral or near-white background,
- dark text,
- one primary accent,
- one optional secondary accent,
- one limitation or warning color.

Use accent color only for:
- key numbers,
- proposed method labels,
- important highlight states,
- selected comparisons,
- caution markers.

## Spacing

Keep generous whitespace.
Preserve visual rhythm.
Avoid crowded slides.

## Layout

Use a consistent slide grid.
Preserve safe margins.
Support projector readability.

## Components

Use only components that improve explanation:
- title block,
- result card,
- comparison block,
- callout,
- equation panel,
- figure placeholder,
- ablation block,
- limitation block.

Avoid decorative chrome.

## Motion

Use subtle fades and slight movement.
Keep transitions between 200ms and 500ms when possible.
Respect reduced motion preferences.

Do not use:
- bounce,
- large zooms,
- 3d effects,
- parallax,
- flashy transitions.

## Figures

Redraw or simplify when the original paper visual is too dense.
Use placeholders only when necessary.

## Tables

Prefer focused comparison tables.
Highlight the row or value that matters.

## Equations

Only show equations that materially improve understanding.
Every equation should have a nearby plain-language explanation.

## Anti-patterns

Never produce:
- large hero marketing sections,
- meaningless icons,
- overuse of cards,
- tiny screenshots of the paper,
- full abstract paragraphs,
- unexplained equations,
- unreadable tables,
- gradient-heavy landing-page styling.
